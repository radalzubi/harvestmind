# Specification traceability

V2 introduces an actual continuous/MILP network decision space; it is not another
finite menu of buffers. **A full enterprise-parity/commercial-validation claim is
not made.** Final engineering verdict is governed by retained failures, not feature
count or tests compiling. The original dirty Indiana checkout is untouched.

| Spec parts | Implemented path | Boundary / outstanding evidence |
|---|---|---|
|1–2|contracts, dependency map, strict as-of state|Partial receipts and revision reconciliation depend on operator data; source records combine supplier/quote/route fields|
|3|Continuous source quantities, real integer packs/MOQ|No 0/50/100 source restriction|
|4–5|SKU/location/expiry network balances and physical transfers|Direct network MPC; not separately benchmarked GS-MEIO|

The goal of the scope table is to expose remaining gaps, not turn partial
capabilities into checkmarks for the entire original specification.
