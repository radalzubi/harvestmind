# Venture Readiness Scorecard

_A scorecard to be honest with yourself about where HarvestMind
stands on the venture-readiness curve. Each category has explicit
green / yellow / red criteria and the evidence that would move the
status. Designed to be re-scored quarterly._

The goal of this document is **not** to tell investors HarvestMind
is venture-ready. The goal is to tell **the founders** what is
actually true. Lying to yourself in this document destroys the
value of the document.

---

## How to score

For each category:
- Read the green / yellow / red descriptions
- Choose the one that is honestly true today
- Record the date and any supporting evidence
- Set a target: "what would move this to the next color and when?"

A venture-fundable position is **not** "all green." Most fundable
seed-stage companies score 4–6 greens, 3–4 yellows, and 1–2 reds.
What matters more than the count is whether you can credibly tell
an investor what each yellow/red is and what would move it within
6 months.

## How to use this document

1. **Re-score every quarter** with date stamps. Keep the history.
2. **Show the current scorecard to advisors before pitching them.**
   Saying "here is exactly where we are, and here is what would
   move it" earns more credibility than any deck.
3. **If a category stays red for 6 months despite effort, surface
   it as a problem.** Either the bet is wrong, the execution is
   wrong, or the resourcing is wrong. Don't paper over it.
4. **When pitching investors, show the 6-month target, not the
   current state.** State both. The gap between them is what you
   are asking the investor to fund.
5. **Re-read this document before sending any inflated email or
   slide.** If the email implies a score better than reality, fix
   the email before sending it.

## What would change this scorecard's structure

These criteria are themselves hypotheses about what matters for
venture-readiness in this category. If, after 6–12 months of
operator engagement, we learn that one of these categories doesn't
matter or that a different category matters more, update the
scorecard structure.

Likely candidates for revision after first 3 pilots:

- "Integration pull" may matter less than expected if Path B
  (productized diagnostic) emerges as the strongest path
- "Product usage frequency" may matter less than expected if
  operators prefer quarterly engagements over weekly
- A new category — "regulatory anchor strength" — may need to be
  added if FSMA-204 timing pulls forward or back materially

The point of the scorecard is to be honest, not to be permanent.
