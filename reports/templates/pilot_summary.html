How it works

  1. We analyse your order history and supplier delivery patterns.
  2. We model uncertainty: weather, demand swings, supplier reliability.
  3. We tell you exactly how much to commit each week to minimize waste and emergency spot purchases while keeping shelves full.
Analysis based on {{ n_backtest_origins }} rolling-origin backtest periods using historical order and delivery data. Projections use the two-stage stochastic planning method (Mateo et al. 2016, Computers & OR). Confidence range ±25% reflects backtest variance. Actual results depend on future demand and supply conditions.

How we tested this

We replayed {{ n_backtest_origins }} historical {{ horizon_weeks }}-week planning periods using only the information available at the time. For each period we compared what really happened against four planning approaches: a naive "same week last year" plan, a deterministic linear program, a robust LP, and the HarvestMind two-stage stochastic plan.
