# FMCG sample uploads (SYNTHETIC ILLUSTRATIVE)

Generated by `synthetic/fmcg/distributor_sim.py` (archetype E, seed 1,
12 SKUs, 60 weeks). Not a real distributor. Upload each file to the
matching staging table, in eaches:

| file | table |
|---|---|
| `skus.csv` | `stg_fmcg_skus` |
| `orders.csv` | `stg_fmcg_orders` |
| `purchase_orders.csv` | `stg_fmcg_purchase_orders` |
| `receipts.csv` | `stg_fmcg_receipts` |
| `inventory.csv` | `stg_fmcg_inventory` |
| `promotions.csv` | `stg_fmcg_promotions` |

Then `POST /fmcg/plan`. Column headers are the canonical names; common ERP
headers (`Item`, `Qty`, `PO Number`, `On Hand`, ...) are mapped
automatically by `COLUMN_MAPS` in `ingestion/csv_ingestor.py`.
